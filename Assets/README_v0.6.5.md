# 山海驭灵录 M1 v0.6.5 · 星金营地自然扩展版

这是 v0.6.4 首轮场景检查后的独立修正版，旧版继续保留。

## 本版内容
- 三个可跳转世界均扩展为 120 米自然地形，取消硬质方盒边界，增加远近坡地、弯曲石土路径和雾化层次。
- Kenney Nature Kit 的 CC0 树、岩石、草花、石桥、木座与篝火素材；根据 Unity 导入的实际网格尺寸调整比例和分布。
- 星金营地的暖光祭台、溪谷的石桥与青玉晶脉。
- 可驯服异兽：岚角灵兽、Blender 新制赤尾灵狐、蓝色翼兽。三个世界均可遇到全部三种。
- 宠物图鉴、收服条件、协同战斗和 1/2/3 技能；鼠标直接转视角、滚轮缩放、Esc 暂停。
- 白模检查会核对每个世界里的玩家、敌人、三只异兽、宠物系统、两个传送门和地形碰撞。

## 操作说明
- WASD 移动，空格跳跃，Shift 闪避。
- 移动鼠标转动镜头，滚轮缩放；左键或 J 攻击，Q 灵纹。
- 靠近异兽按 E；赤尾灵狐需先 Q 再在 7 秒内 E。岚角需削弱到 45% 生命以下，蓝色翼兽需削弱到一半以下。
- P 打开队伍面板，放出异兽后靠近敌人协战；1/2/3 使用技能。靠近传送门按 E。
- Esc 暂停，可继续或退出。

# 山海驭灵录 M1 目标

> 当前版本：v0.7.5 工程（仓库 `main` 分支），v0.7.9 改动已写入工程，尚未构建试玩。
> 任务明细见 `tasks.yaml`。

## G1 · 验证 v0.7.9 可玩

**目标**：v0.7.9 能从 Unity 菜单打包并启动，核心新功能可以正常工作。

**验收标准**
- 菜单 `Shanhai → Build v0.7.7 · 3D 角色 + 大地图（B 版）` 构建成功，游戏能启动。
- 100 米刷新圈内能刷出野生灵兽，圈外消失，按 H 能显示/隐藏圆圈。
- 按住 F 采集资源点约 1.1 秒，每点 4 次，采空后 2 分钟重生。
- Unity Console 无红色报错。

**状态**：待用户在电脑上构建（见 T1.1）。

## G2 · 模型与贴图导入优化（不改外观）

**目标**：降低运行时的内存和加载开销，画面基本不变。

**范围**
- 贴图：调整最大尺寸和压缩方式（Bark、Leaves、Rocks 等 2048 贴图）。
- FBX：开启网格压缩（Medium），关闭 Read/Write。

**验收标准**
- 在 `optimize-import` 分支中完成修改，两次 commit 分别对应贴图和模型。
- 用户在 Unity 中打开检查，画面没有明显变差。
- 构建试玩版通过。

**约束**：在分支中修改，`main` 不动，直到用户确认效果。

## G3 · 减面（会改变外观，需确认后再做）

**目标**：降低地形网格（约 39MB）和生物模型的面数。

**前置条件**：G2 完成并通过用户确认。

**验收标准**：减面后的模型在游戏中的轮廓和比例可接受，用户确认后合并。

## G4 · 数据与文档统一

**目标**：消除文档之间的矛盾，让代码和文档一致。

**要处理的矛盾**
- 灵兽数量：v0.7.5 写 16 种，v0.7.9 写 20 种。以代码为准。
- 世界尺寸：320 米、640 米、800 米并存。以当前代码为准。
- `README_启动与内容说明.md` 仍是 v0.3 内容。

## G5 · 工程规范

**目标**：统一输入方式，清理过时资料，让新版本流程稳定。

- 从旧版 Input Manager 迁移到 Input System 包（不影响玩法，单独分支做）。
- 历史的 `M1WorldBuilder` 和 `M1WindowsBuild` 脚本保留作参考，不删除。
- 每个版本的构建和验证记录写入 `04_验证记录\<版本号>\`（仓库外）。

## G6 · 后续功能（暂不排期）

- 存档功能。
- 宠物队伍在世界之间切换后持久化。

## G7–G12 · 试玩评价后的分阶段优化（v0.8.1 起）

依据 2026-10-20 试玩评价，详表见 `00_项目管理\优化路线图_v0.8.1起.md`。

- **G7 可读性与 bug（v0.8.1）**：攻击不随镜头远近变化、战斗反馈、碰撞统一、版本标识统一。
- **G8 引导与界面（v0.8.2）**：分步新手提示、HUD 清晰、画面亮度与层次。
- **G9 动作与模型（v0.8.3）**：主角姿态、鸟类与灵蝶飞行、灵龟升级、猫系区分、灵兽攻击动作（Blender + 外部素材 / AI 建模）。
- **G10 场景表现（v0.9）**：营地与地标山海化、三个世界地貌差异。
- **G11 灵兽行为（v0.9.x）**：图鉴习性落到野外行为。
- **G12 收服后的玩法（v1.0）**：伙伴能力、成长与区域解锁、存档。

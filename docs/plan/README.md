# 计划目录说明

这个目录把项目的目标、任务、决策和待确认问题整理成可以直接查询和更新的文件。

| 文件 | 用途 | 给谁看 |
|---|---|---|
| `goals.md` | 阶段目标和验收标准（人读） | 所有人 |
| `tasks.yaml` | 任务清单，字段统一，方便脚本和 Claude Code 查询、更新 | Claude Code / 脚本 |
| `decisions.md` | 已经确定的决策，附日期和理由 | 所有人 |
| `open-questions.md` | 还需要用户确认的事项 | 用户 |

## 任务状态约定

- `done`：已完成并验证。
- `in_progress`：正在做。
- `pending`：待开始，依赖项已满足。
- `blocked`：被依赖项或外部条件卡住，需要写明原因。
- `needs_user`：需要用户在电脑上操作或确认，Claude 无法单独完成。

## 更新规则

1. 改任务状态时，只改 `tasks.yaml` 里对应条目的 `status` 和 `updated` 字段，然后在 `decisions.md` 记录重要变更。
2. 新增任务用新的 `id`，不要复用旧 `id`。
3. 删除或覆盖文件前，先征得用户明确同意。
4. 不要提交 `Library`、`Temp`、`Logs` 等缓存目录。
